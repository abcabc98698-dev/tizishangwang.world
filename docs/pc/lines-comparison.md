# 什么是 IEPL 跨境专线？公网中转、BGP 入口与直连节点延迟与丢包真实评测

> **【Answer-First 核心技术结论】**  
> 1. **IEPL (International Ethernet Private Line，国际以太网专线)**：是由中国电信、联通等一级运营商直接铺设的点对点跨境内网物理光纤。**最关键物理特性：数据在境内机房直接进入运营商企业内网光纤，穿过边界抵达境外机房，全程根本不经过 GFW 公网审查节点**。因此专线具备三大不可替代的优势：**零敏感期封锁风险、极端恶劣网络下 0 丢包、延迟始终稳定在物理极限（如深港专线 5~8ms）**。  
> 2. **公网隧道中转（Transit Tunnel）**：数据包通过国内公网服务器打包加密后，强行通过普通的国际海底公网光缆传输。**致命弱点**：数据包必须穿透 GFW 审查节点，且必须在晚高峰与全国亿万跨国流量争抢拥挤的国际出口公网带宽，晚高峰丢包率通常在 15%~40% 之间剧烈震荡。  
> 3. **选型铁律**：用于日常跨境办公、Zoom 远程跨国会议、高频 ChatGPT 生产力，**必须选用纯 IEPL 专线机场**。

| :--- | :--- | :--- | :--- |
| **物理传输路径** | 国内机房 ──▶ **运营商内网光缆** ──▶ 境外机房 | 国内机房 ──▶ **公网国际出口 (GFW)** ──▶ 境外 | 本地宽带 ──▶ **公网跨洋单跳** ──▶ 境外 |
