# 关于我们：梯子上网 (tizishangwang.world) 实验室与专家团队

> **【我们的核心使命】**  
> **tizishangwang.world** 致力于成为中文互联网最专业、客观、严谨的桌面端（Windows / macOS）跨境网络加速、开源代理客户端及电信基础设施技术审计知识库。我们拒绝任何虚假评测、拒绝对劣质商家的虚假背书，始终坚持通过物理真机、全周期自动化抓包及严格的丢包率遥测，为中国科研工作者、外贸从业人员、程序员与高频数字游民提供真正可靠的选型大系。

## 二、我们的三大核心评测准则 (Core Principles)

1. **坚持物理实测 (Empirical Telemetry)**：  
   所有测速数据与延迟报表均来自部署在境内真实宽带（中国电信、中国联通、中国移动 1000M FTTH）的探针服务器，在每晚 20:30~22:00 高峰期进行自动化抓包测试，绝不引用商家官方宣传材料。
2. **坚持技术透明 (Technical Transparency)**：  
   公开所有测试环境的参数细节，包括客户端版本、测试协议、DNS 模式及海外落地 IP 类型，让每一项评测结论都具备可复现性。
3. **坚持利益冲突隔离 (Editorial Independence)**：  
   虽然本站为了维持服务器硬件与千兆测试宽带的高昂成本接入了合规商业赞助链接，但赞助商**绝不能购买排名的提升，也绝不能干预任何客观负面评价的发布**。
