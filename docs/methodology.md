# 评测方法论：科学上网工具与专线机场测试标准规范

> **【Answer-First 方法论总纲】**  
> 为了确保全网评测排行的公信力，**tizishangwang.world** 制定了严格的《桌面端跨境网络链路评测标准 (DT-NCS v4.0)》。我们综合考量 **晚高峰稳定性（40%）、网络物理延迟与抖动（25%）、流媒体与 AI 原生解锁率（20%）、客户端生态与使用门槛（15%）** 四大核心维度，通过统一的量化数学模型计算综合评分。

## 一、物理测试环境与探针节点配置

所有基准测速均在标准化硬件与真实家庭宽带环境下执行，杜绝机房与机房之间的“内网对测假数据”：

*   **境内测试探针**：
    *   探针 A：中国电信 1000M / 100M 上行 (华南机房/家庭双环境)
    *   探针 B：中国联通 1000M / 80M 上行 (华东环境)
    *   探针 C：中国移动 500M / 50M 上行 (华北环境)
*   **测试客户端硬件**：
    *   PC 平台：Intel Core i7-13700K / 32GB RAM / Windows 11 Pro 23H2 (开启 Wintun TUN 模式)
    *   Mac 平台：Apple M3 Pro / 18GB RAM / macOS Sonoma 14.5 (开启 Network Extension 原生架构)
*   **测试时间口径**：
    *   全天常规巡检：每隔 6 小时自动执行一次连通率握手测试；
    *   **晚高峰极端压测：每晚 20:30 ~ 22:30（国际海底公网出口拥堵峰值时段）** 执行单节点 200MB 文件高吞吐测速。

## 二、四大评分维度与加权算法模型

```
┌─────────────────────────────────────────────────────────────┐
│              tizishangwang.world 综合评级模型               │
│                                                             │
│   综合得分 S = W1×0.40 + W2×0.25 + W3×0.20 + W4×0.15        │
└─────────────────────────────────────────────────────────────┘
```

### 1. 晚高峰稳定性 (Weight: 40%)
*   **丢包率 (Packet Loss)**：连续发送 500 个 UDP/ICMP 探测包，丢包率 `< 0.5%` 得满分；丢包率 `> 5%` 扣减 50 分；
*   **持续在线率 (Uptime SLA)**：以自然月为周期，记录机房发生宕机故障的累计时长，`> 99.8%` 为及格基准。

### 2. 延迟与抖动 (Weight: 25%)
*   **深港 / 沪日近端延迟**：深港 IEPL 专线物理往返延迟 (RTT) 需控制在 30ms 以内；
*   **网络抖动 (Jitter)**：网络延迟标准差需 `< 2.0ms`。极低的抖动是保障 Zoom / Google Meet 视频会议不卡顿的核心指标。

### 3. 解锁能力与 IP 纯净度 (Weight: 20%)
*   使用自动化脚本检测是否原生解锁 Netflix、Disney+、YouTube Premium、TikTok；
*   使用自动化 API 探测 OpenAI (ChatGPT Plus) 与 Anthropic Claude 3.5 Sonnet，验证是否报错 403 或跳出人机五秒盾。

### 4. 客户端生态与易用性 (Weight: 15%)
*   是否提供自研免配置客户端；
*   是否兼容现代开源主流协议（Mihomo / sing-box）；
*   遇到断网或端口死锁时的自动排障与重置能力。

## 三、数据修正与争议处理流程

1. **自动告警**：当监测系统发现某品牌核心节点连续 3 次抽测出现断连时，系统会在 15 分钟内将该节点状态标记为 `Degraded` 并扣减实时健康分；
2. **人工复核**：工程师团队使用备用探针验证问题是否由本地 ISP 引起；
3. **品牌方反馈**：若品牌方完成了硬件线路扩容或落地 IP 轮换，可申请重新执行 24 小时完整周期压测，复测合格后方可更新榜单数据。
