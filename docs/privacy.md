# 隐私政策 (Privacy Policy)

> **生效日期**：2026-10-01  
> **最后更新**：2026-10-23  

**tizishangwang.world**（以下简称“本站”或“我们”）极度重视用户的个人数据与隐私安全。本隐私政策旨在向您说明我们在您访问本站时如何收集、使用、存储您的信息，以及您所拥有的权利。

---

## 一、我们收集的信息范围

本站作为一个纯静态技术文档与评测知识库，严格坚持 **「数据最小化（Data Minimization）」** 原则：

1. **我们绝不收集敏感个人身份信息**：本站不需要用户注册账号，不要求输入手机号、身份证号、家庭住址或银行卡信息。
2. **服务器访问日志**：出于排查恶意网络攻击（如 DDoS、暴力扫描）与系统运维需要，我们的 Web 服务器可能会自动记录基本的访问日志，包括：访问时间戳、请求的 URL 路径、请求状态码、浏览器 User-Agent 以及匿名化的公网 IP 地址。该日志仅保留 30 天且绝不与任何个人身份关联。
3. **Cookies 与本地存储**：本站仅在您的浏览器本地存储必要的偏好设置（如暗黑模式/亮色模式切换状态），不使用任何跨网站追踪 Cookie。

---

## 二、第三方服务与外部链接

1. **开源客户端下载源**：本站提供的客户端下载链接均直接指向 GitHub 官方开源 Releases，我们不存储任何经过第三方修改的二进制可执行文件。
2. **赞助商推广链接**：当您点击本站的商业专线或机场链接时，您将被重定向至第三方服务商的官方网站。第三方服务商拥有其独立的隐私政策与数据收集规则，我们建议您在第三方网站输入支付信息前仔细查阅其隐私条款。

---

## 三、数据安全与儿童隐私

我们采用现代安全措施（全站强制 TLS 1.3 加密传输、HSTS 严格安全标头）保护数据通信。本站内容仅面向具备完全民事行为能力的成年人，绝不故意收集未满 18 周岁未成年人的任何信息。

---

## 四、隐私权联系方式

如果您对本隐私政策有任何疑问，请通过电子邮件联系我们的数据安全保护官：`privacy@tizishangwang.world`。
