# 多电脑与家庭团队设备并发方案：合租共享、设备数限制与局域网共享代理

> **【Answer-First 核心技术结论】**  
> 1. **机场是按「设备数」还是按「IP 数」限制的？** 90% 以上的正规商业机场采用 **「同时在线公网 IP 数限制」**，而不是客户端本地设备数。例如：套餐规定“限制 2 个公网 IP 在线”，意味着**只要在同一个家庭或办公室 Wi-Fi 下（所有设备对外呈现同一个路由器公网出口 IP），即使连入 10 台电脑和手机，也仅算作 1 个 IP 在线，绝不会超限封禁**；但如果一台电脑在公司、另一台在家、手机在外面用移动数据，则算作 3 个不同 IP，会触发并发限制。  
> 2. **局域网免配置共享翻墙神器**：如果不想在家里每台电脑上都配置客户端，可以在一台常开的台式机上打开 Clash Verge Rev 的 **「允许来自局域网的连接 (Allow LAN)」**，其他笔记本、平板无需安装任何翻墙软件，只需在 Wi-Fi 设置中将 HTTP 代理指向台式机内网 IP（如 `192.168.1.100:7890`），即可全屋无缝翻墙。

## 一、多端并发方案全要素对比大表

| 实现方案 | 部署成本与门槛 | 设备数量上限 | 对主设备依赖 | 适合场景 |
| :--- | :--- | :--- | :--- | :--- |
| **同 Wi-Fi 局域网直接连接** | 零门槛，各客户端独立导入 | 无限制 (共享1个公网IP) | 无依赖，各自独立运行 | **家庭或小型工作室日常上网** |
| **主电脑开启 Allow LAN 代理共享** | 低门槛，仅需勾选1个开关 | 视主电脑网络吞吐而定 (10~20台) | 需主电脑保持开机常驻 | **不想在其他设备装软件、电视盒子** |
| **硬路由 / 软路由透明网关 (OpenWrt)** | 较高，需购买软路由硬件并刷机 | 全屋无死角全量接管 | 依赖路由器硬件网关 | **全屋智能家居、PS5/Xbox 游戏主机** |

## 二、PC 客户端一键共享局域网代理操作指南

### 步骤 1：主电脑开启共享开关并查内网 IP
1. 打开 Clash Verge Rev 的「设置」，找到 **「允许局域网连接 (Allow LAN)」** 并开启。
2. 打开 Windows CMD 运行 `ipconfig`，查看「IPv4 地址」（例如 `192.168.31.50`）。

### 步骤 2：在其他设备上配置代理
1. 在其他笔记本或手机的 Wi-Fi 设置中，点击当前连接的 Wi-Fi 详情。
2. 找到「HTTP 代理」，切换为「手动」：
   - **服务器 (主机名)**：填入主电脑内网 IP `192.168.31.50`；
   - **端口**：填入 `7890`。
3. 保存后打开网页，副设备瞬间实现科学上网！
