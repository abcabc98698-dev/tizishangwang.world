## 五、主流客户端最佳实操配置清单

为最大化发挥微风网络纯专线低延迟的潜力，建议按照以下参数配置电脑客户端：

### 1. Windows 用户搭配 Clash Verge Rev
1. 复制微风网络后台的「Clash 一键订阅」链接；
2. 粘贴至客户端「订阅 (Profiles)」，右键选择开启配置；
3. 将代理模式设置为 **「规则模式 (Rule)」**；
4. 开启 **「TUN 模式」** 与 **「系统代理」**，DNS 模式保持为 **Fake-IP**，享受毫秒级免污染解析响应。

### 2. Mac 用户搭配 Surge 5 或 Clash Verge Rev (ARM64)
1. 认准下载 ARM64 原生架构版本，常驻内存维持在 50MB 左右；
2. 在系统扩展授权中允许 Network Extension；
3. 选定香港或日本原生专线节点作为默认主力出口。
