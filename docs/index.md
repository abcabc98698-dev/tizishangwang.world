## 二、电脑翻墙底层技术架构：专线（IEPL/IPLC）与公网隧道解析

对于桌面电脑用户而言，翻墙工具的体验有 80% 决定于**跨境网络链路的物理架构**，仅有 20% 取决于客户端设置。了解底层通信链路是避免被虚假宣传欺骗的关键。

### 1. 物理链路的三种代际差异

| 链路类型 | 物理传输介质 | 是否经过 GFW 防火墙 | 晚高峰丢包率 | 典型延迟 (亚洲近端) | 综合评级 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **IEPL / IPLC 国际专线** | 跨境陆缆 / 海底内网裸光纤点对点私网直连 | **完全不经过**（物理隔离） | **< 0.1%**（极度平稳） | **20ms ~ 45ms** | ⭐⭐⭐⭐⭐ (五星推荐) |
| **国内 BGP 优化中转** | 国内骨干机房接收，公网加密隧道跨境直连 | **经过**（高强度加密混淆传输） | 2% ~ 8%（偶有波动） | 45ms ~ 75ms | ⭐⭐⭐⭐ (性价比首选) |
| **传统直连 / 公共梯子** | 用户本地宽带通过公网直连海外 VPS 服务器 | **深度审查**（直接暴露在 GFW） | 15% ~ 60%（晚高峰严重断流） | 150ms ~ 350ms | ⭐ (淘汰边缘) |

<TopologyView title="IEPL 国际内网专线 vs 传统公网隧道网络拓扑可观测图" />

正如上图所示，**IEPL（International Ethernet Private Line）** 专线是由服务商合规租用的跨境企业局域网链路。用户从本地发起的访问流量在进入国内 BGP 骨干入口（如上海、广州电信/联通机房）后，直接通过内网光纤点对点穿透边界，**数据根本不流经国际公网出口**。因此，无论外界审查策略如何波动，专线网络都能保障 0 丢包和恒定的毫秒级延迟。

## 七、电脑翻墙核心操作系统实战指引 (OS Quick Guides)

针对不同电脑操作系统的用户，配置翻墙工具时的侧重点与易错点截然不同：

### 1. Windows 11 / Windows 10 用户核心须知
- **系统代理的盲区**：Windows 原生「系统代理（IE 代理）」只能拦截遵循操作系统代理规范的应用（如 Chrome、Edge、Firefox）。而 Windows 终端（PowerShell/CMD）、Git 命令行、Telegram 桌面版、部分外服网游并不会自动走系统代理。
- **解决方案**：在客户端（如 Clash Verge Rev）中开启 **TUN 模式（虚拟网卡）**。TUN 模式会通过 Wintun 驱动在 Windows 中创建一个虚拟网络适配器，从操作系统网络驱动层强制拦截所有出站流量，实现 100% 全局接管。
- **解除 UWP 回环限制**：Win10/Win11 内置的 UWP 应用（微软商店、Xbox、邮件）受到 AppContainer 沙箱隔离，默认无法访问 `127.0.0.1` 本地代理。必须通过客户端内置的「UWP 回环工具」一键勾选豁免。
- 深度实战请参阅：👉 **[Windows 科学上网万字级全要素配置实战大系](/windows/)**。

### 2. macOS (Apple Silicon M系列 / Intel) 用户核心须知
- **芯片架构鉴别**：Mac 用户在下载客户端 dmg 安装包时，务必注意区分 **ARM64（Apple Silicon M1/M2/M3/M4）** 与 **x64（Intel 芯片）**。下载对应芯片架构的原生版本可降低 70% 的运行发热并减少内存损耗。
- **网络扩展权限（Network Extension）**：首次在 macOS 开启增强模式（TUN）时，系统会弹出系统扩展安全警告，需要在「系统设置 → 隐私与安全性」中手动点击允许并输入锁屏密码。
- 深度实战请参阅：👉 **[Mac 科学上网全景选型与 macOS 系统适配指南](/mac/)**。
